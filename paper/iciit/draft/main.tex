\begin{abstract}
Reverse engineering the latent data-generating mechanisms of tabular datasets is a fundamental inverse problem that challenges inductive reasoning, automated feature engineering, and programmatic comprehension in artificial intelligence. While Large Language Models (LLMs) demonstrate remarkable proficiency in forward mathematical reasoning and code synthesis, their capacity to infer, isolate, and reconstruct hidden parametric transformation pipelines solely from observational input-output data tables remains underexplored. In this work, we present the \textbf{Tabular Transformation Discovery Harness}, an autonomous, two-tier evaluation framework designed to benchmark LLM agents on inverse tabular induction across six standardized structural complexity classes (from Class 0: Atomic Unary to Class 5: Deep Hybrid ASTs) spanning eight diverse real-world domains. The harness enforces strict epistemic isolation: an agentic discovery phase operating in an iterative, sandbox stateless-RAM Read-Eval-Print Loop (REPL) environment with adaptive resource budgets is decoupled from an independent, black-box functional evaluation phase on hidden holdout distributions. In the REPL sandbox, the agent iteratively tests candidate Python transformations, inspects execution output, and refines mathematical hypotheses under hard budget constraints. We conduct extensive empirical evaluations comparing frontier coding and multimodal agents (Claude 3.5 Sonnet, Gemini 2.0 Flash), a lightweight frontier model (GPT-4o mini), and a naive combinatorial brute-force reference baseline across 48 standardized benchmark tasks ($N=48$, 8 datasets $\times$ 6 complexity classes in a balanced full-factorial design). Our empirical findings reveal a pronounced divergence across paradigms: while Claude 3.5 Sonnet achieves a 70.8\% submission rate with 0.811 conditional transformed accuracy (0.575 penalized accuracy), Gemini 2.0 Flash achieves 0.844 conditional transformed accuracy but exhibits an over-conservative stopping policy (50.0\% submission rate, 0.422 penalized accuracy). GPT-4o mini achieves a 100\% submission rate but suffers substantial degradation from 1.000 on Class 0 to 0.250 on Class 5 (with a partial rebound to 0.375 on Class 4 piecewise logic), and depth-3 combinatorial brute-force enumeration collapses on deep interaction graphs (0.375). Furthermore, through a three-mode ablation study, we demonstrate that direct symbolic generation without execution feedback fails almost entirely (3.6\% conditional transformed column accuracy, 2.1\% penalized), whereas revealing oracle operator vocabularies yields perfect 100\% conditional functional recovery on submitted tasks (66.7\% penalized accuracy). This demonstrates that while programmatic compilation from known operators is highly reliable in frontier models, hypothesis search under observational uncertainty and budget-constrained stopping heuristics remain the primary operational bottlenecks. All code, benchmark tasks, and evaluation harnesses are made open-source at \url{https://github.com/mini-smart-lab/tabular-transformation}.
\end{abstract}

\section{Introduction}

Tabular data remains the predominant data modality in mission-critical industrial, scientific, and financial domains~\cite{borisov2022deep,grinsztajn2022tree}. Despite the recent ascendancy of Large Language Models (LLMs) across natural language and software engineering domains~\cite{achiam2023gpt4,anthropic2024claude35,geminiteam2024gemini,jimenez2024swebench}, tabular data structures present unique fundamental challenges: permutation-invariant columns, heterogeneous distributions, non-linear cross-column correlations, and rigid numerical dependencies that cannot be inferred purely via autoregressive token modeling~\cite{xu2019synthesizing,kotelnikov2023tabddpm,sui2024table}.

A central challenge at the intersection of automated machine learning and program synthesis is \emph{inverse tabular transformation reasoning}: given an observational baseline dataset $\mathcal{D}_{\text{before}}$ and an engineered or transformed dataset $\mathcal{D}_{\text{after}}$, can an autonomous AI agent infer, formulate, and execute the exact latent programmatic transformation $\mathcal{T}$ such that $\mathcal{T}(\mathcal{D}_{\text{before}}) \approx \mathcal{D}_{\text{after}}$? Developing this capability is critical for auditing and reverse-engineering legacy ETL (Extract, Transform, Load) pipelines that lack documentation, automating feature discovery in predictive modeling~\cite{cranmer2020frontier}, reconstructing scientific equations from observational physical tables~\cite{schmidt2009distilling,udrescu2020ai}, and identifying potential data privacy leakage in synthetic anonymization protocols~\cite{stadler2022synthetic}.

While popular benchmark suites such as HumanEval~\cite{chen2021evaluating} and SWE-bench~\cite{jimenez2024swebench} evaluate \emph{forward} reasoning—where formal specifications or natural language descriptions dictate desired program semantics—inverse tabular induction requires \emph{scientific hypothesis formation under uncertainty}. The agent operates in a Read-Eval-Print Loop (REPL) environment—an interactive programming shell where candidate code snippets are executed immediately in an isolated interpreter, returning runtime stdout, stderr, and numerical summaries to guide subsequent reasoning. Within this REPL paradigm, the agent must:
\begin{enumerate}
    \item Inspect multivariate numeric distributions across high-dimensional feature spaces;
    \item Disentangle candidate mathematical hypotheses (e.g., distinguishing logarithmic scaling from power-law decays or piecewise segmentations);
    \item Interactively experiment using executable code in the sandboxed REPL;
    \item Synthesize a clean, self-contained, parametric Python function $\texttt{transform}(\texttt{df})$ that generalizes out-of-distribution.
\end{enumerate}

Prior benchmarks attempting to evaluate programmatic reasoning suffer from critical methodological shortcomings. First, many rely on synthetic toy distributions (e.g., uniform or normal random variables) rather than authentic tabular benchmarks, ignoring the multi-collinearity, skewed kurtosis, and boundary anomalies inherent in empirical datasets. Second, existing evaluation frameworks often execute candidate solutions in the same environment where test data resides, introducing severe risks of data leakage and contamination. Third, standard evaluation metrics frequently conflate \emph{code generation accuracy} with \emph{hypothesis search efficiency}, making it impossible to diagnose whether an agent failed because it could not discover the underlying mathematical law or because it made a trivial syntactic error during program synthesis.

To overcome these fundamental limitations, we propose the \textbf{Tabular Transformation Discovery Harness}, a rigorous research framework featuring:
\begin{enumerate}
    \item \textbf{A Formal Taxonomy of 6 Structural Complexity Classes:} Ranging from atomic unary operations (Class 0) to deep hybrid Abstract Syntax Trees (ASTs) containing piecewise conditionals and multi-column interactions (Class 5).
    \item \textbf{A Two-Tier Epistemic Isolation Architecture:} Tier 1 provides an interactive REPL discovery sandbox where the agent executes arbitrary Python code on training split pairs $(\mathcal{D}_{\text{train\_before}},$ $\mathcal{D}_{\text{train\_after}})$, governed by an Adaptive Tiered Budget Controller. Tier 2 executes the submitted script in a fresh container on an unobserved holdout set $\mathcal{D}_{\text{test\_before}}$, strictly isolated from $\mathcal{D}_{\text{test\_after}}$ (Figure~\ref{fig:two_tier_arch}).
    \item \textbf{A Multi-Domain Benchmark Suite Across 8 Real-World Datasets ($N=48$ Tasks):} Sourced from diverse domains (aeronautics, clinical medicine, civil engineering, computer systems telemetry, food chemistry, oncology, economics, and security signal processing), compiled into a balanced full-factorial design across all 6 complexity classes (8 datasets $\times$ 6 classes = 48 tasks).
    \item \textbf{A Cross-Paradigm Empirical Study:} Benchmarking a frontier coding agent (Claude 3.5 Sonnet), a frontier multimodal agent (Gemini 2.0 Flash), a lightweight frontier model (GPT-4o mini), and a naive depth-3 combinatorial enumeration reference baseline.
    \item \textbf{A Rigorous 3-Mode Ablation Protocol:} Isolating the relative contributions of direct parametric reasoning (no tools), interactive hypothesis testing via REPL, and oracle operator disclosure on Gemini 2.0 Flash.
\end{enumerate}

All code, benchmark datasets, and evaluation harnesses are publicly available at \url{https://github.com/mini-smart-lab/tabular-transformation}.

\section{Related Work}

\subsection{Tabular Representation Learning and LLMs}
Tabular data presents distinct challenges for deep neural networks due to heterogeneous column distributions, non-spatial correlation, and varying sparsity~\cite{borisov2022deep,grinsztajn2022tree}. While gradient-boosted decision trees historically dominated supervised tabular benchmarks, recent research has explored adapting deep foundation models and LLMs to tabular structures. Early efforts serialized tabular rows into natural language prompts for forward classification and regression (TabLLM~\cite{hegselmann2023tabllm}). In parallel, instruction-tuned models such as Table-GPT~\cite{li2024tablegpt} and structural table benchmarks by Sui et al.~\cite{sui2024table} evaluate table understanding and question answering. More recently, scalable tabular foundation models based on In-Context Learning (ICL)—such as TabICL~\cite{qu2025tabicl} and TabICLv2~\cite{qu2026tabiclv2}—employ specialized two-stage architectures with column-then-row attention mechanisms capable of performing in-context prediction across large tabular samples. 

However, all these existing models operate exclusively in the \emph{forward} predictive or natural language regime: given observed training instances or question prompts, they predict target labels or textual answers via text-to-text generation without an interactive execution sandbox. In contrast, our work investigates \emph{inverse program induction}: given observational table pairs before and after transformation, an autonomous agent must explicitly infer, formalize, and synthesize the latent mathematical code pipeline that generated the transformed data.

\subsection{Program Synthesis, Table Wrangling, and Symbolic Regression}
In program synthesis and data wrangling, programming-by-example (PBE) frameworks such as FlashFill~\cite{gulwani2011flashfill} and Foofah~\cite{jin2017foofah} automatically synthesize string transformations and relational schema reshaping scripts from input-output examples. Similarly, Auto-Pipeline~\cite{yang2021autopipeline} synthesizes data preparation pipelines for machine learning by navigating a discrete library of data cleaning and transformation primitives. However, these classical PBE and table wrangling systems are strictly bounded to discrete relational restructuring (e.g., pivots, regex string splits, joins) and cannot scale to continuous non-linear mathematical equations, cross-column interactions, or stateful empirical distribution scalers.

In numerical domains, symbolic regression aims to uncover closed-form mathematical equations that explain empirical observations~\cite{schmidt2009distilling,udrescu2020ai,cranmer2020frontier}. Genetic programming~\cite{schmidt2009distilling}, AI Feynman~\cite{udrescu2020ai}, and modern evolutionary symbolic regression packages such as PySR~\cite{cranmer2023pysr} utilize Pareto-optimal evolutionary search and physics-inspired modular decomposition to avoid exhaustive combinatorial enumeration. More recently, equation discovery frameworks (e.g., LLM-SR~\cite{shojaee2025llmsr}, LLM-SRBench~\cite{shojaee2025llmsrbench}) prompt LLMs to discover mathematical relationships via program search. 

While tabular transformation discovery can theoretically decompose into $|\mathcal{C}_{\text{trans}}|$ column-wise single-target multivariate regression sub-problems over the input feature matrix $\mathcal{D}_{\text{before}}$, doing so in an end-to-end tabular context introduces three critical structural challenges absent from traditional symbolic regression: (i) unguided discovery of \emph{which} specific columns were modified versus left unchanged; (ii) fitting, parameterizing, and freezing stateful empirical distribution scalers ($\Omega_3$) strictly on training splits to prevent test-set distributional leakage; and (iii) estimating discontinuous piecewise splitting thresholds ($\Omega_5$) alongside branching conditional logic. Established symbolic regression engines assume continuous analytical expressions and do not natively support tabular schema manipulation, discrete conditioning, or frozen empirical scalers.

\subsection{Autonomous LLM Agents and Execution Sandboxes}
Recent advances in agentic AI combine language model reasoning with external tool execution via iterative ReAct loops~\cite{yao2023react,langgraph2024,madaan2023selfrefine}. In data science, benchmarks such as DS-1000~\cite{lai2023ds1000}, DA-Code~\cite{huang2024dacode}, and feature engineering benchmarks such as FeatEng~\cite{pietruszka2025feateng} (evaluating LLMs as automated data scientists for predictive feature creation) evaluate LLMs on forward code synthesis for tabular manipulation. In software engineering, benchmarks like SWE-bench~\cite{jimenez2024swebench} evaluate autonomous patch generation in repository sandboxes. However, code generation in data science benchmarks relies heavily on natural language prompts or issue descriptions. In contrast, tabular transformation discovery requires unguided inductive hypothesis search from raw numerical arrays without natural language hints.

\section{Problem Formulation and Methodology}

\subsection{Formalization of Tabular Inverse Reasoning}
Let $\mathcal{X} \subseteq \mathbb{R}^M$ denote the feature space of an observational tabular dataset $\mathcal{D}_{\text{before}} = \{\mathbf{x}^{(i)}\}_{i=1}^N \in \mathbb{R}^{N \times M}$ with schema $\mathcal{C}_{\text{before}} = \{c_1, \dots, c_M\}$. Let $\mathcal{T} : \mathbb{R}^M \to \mathbb{R}^P$ be a deterministic, parameterized transformation mapping yielding:
\begin{equation}
    \mathcal{D}_{\text{after}} = \mathcal{T}(\mathcal{D}_{\text{before}}) \in \mathbb{R}^{N \times P}
\end{equation}
with target schema $\mathcal{C}_{\text{after}} = \{\tilde{c}_1, \dots, \tilde{c}_P\}$. Columns modified in-place preserve their original identifiers $c \in \mathcal{C}_{\text{before}}$. When new columns are synthesized through cross-column interactions or piecewise splits, they are assigned anonymized standard identifiers (e.g., target feature replacements or indexed identifiers) to prevent column names from leaking operator identities or source dependencies.

The transformation pipeline $\mathcal{T}$ represents an Abstract Syntax Tree (AST) composed of operators drawn from a discrete library of 24 canonical operators $\Omega = \bigcup_{k=1}^5 \Omega_k$ ($|\Omega| = 24$):
\begin{enumerate}
    \item \textbf{Power \& Unary Arithmetic ($\Omega_1$, 8 ops):} $\text{Square}$ ($x^2$), $\text{SquareRoot}$ ($\sqrt{x}$), $\text{Cube}$ ($x^3$), $\text{CubeRoot}$ ($\sqrt[3]{x}$), $\text{Exp}$ ($e^x$), $\text{Log}$ ($\ln x$), $\text{Log1p}$ ($\ln(x+1)$), and $\text{Inverse}$ ($1/x$).
    \item \textbf{Trigonometric, Hyperbolic \& Activation ($\Omega_2$, 5 ops):} $\text{Sin}$ ($\sin x$), $\text{Cos}$ ($\cos x$), $\text{Tanh}$ ($\tanh x$), $\text{Sigmoid}$ ($\sigma(x) = 1/(1+e^{-x})$), and $\text{Abs}$ ($|x|$).
    \item \textbf{Stateful Distribution Scalers ($\Omega_3$, 2 ops):} $\text{StandardScaler}$ ($(x-\mu)/\sigma$) and $\text{MinMaxScaler}$ ($(x-x_{\min})/(x_{\max}-x_{\min})$).
    \item \textbf{Bivariate Interactions ($\Omega_4$, 4 ops):} $\text{Add}$ ($x_i + x_j$), $\text{Subtract}$ ($x_i - x_j$), $\text{Multiply}$ ($x_i \cdot x_j$), and $\text{Divide}$ ($x_i / x_j$).
    \item \textbf{Piecewise \& Conditional Logic ($\Omega_5$, 5 ops):} $\text{IndicatorZero}$ ($\mathbf{1}_{\{x > 0\}}$), $\text{IndicatorMean}$ ($\mathbf{1}_{\{x > \mu\}}$), $\text{ClipZero}$ ($\max(0, x)$), $\text{PiecewiseLog}$ ($\mathbf{1}_{\{x > 0\}} \ln x$), and $\text{ConditionalInteraction}$ ($\mathbf{1}_{\{x_j > \theta\}} \cdot x_i$).
\end{enumerate}

\noindent\textbf{Parameterization of Stateful Scalers and Empirical Moments:} For stateful distribution-level operators in $\Omega_3$ ($\text{StandardScaler}$ and $\text{MinMaxScaler}$) and conditional operators relying on empirical central tendencies ($\text{IndicatorMean}$ in $\Omega_5$), distribution statistics—specifically the mean $\mu$, population standard deviation $\sigma = \sqrt{\frac{1}{N_{\text{train}}} \sum_{i=1}^{N_{\text{train}}} (x_i - \mu)^2}$ ($\text{ddof}=0$, aligning with \texttt{numpy} and \texttt{scikit-learn} defaults and preventing degree-of-freedom discrepancies relative to evaluation tolerance $\epsilon=10^{-4}$), $x_{\min}$, and $x_{\max}$—are fitted strictly on $\mathcal{D}_{\text{train\_before}}$. Prompt instructions explicitly mandate that the agent embed these empirical parameters as hardcoded floating-point literals within the synthesized $\texttt{transform}(\texttt{df})$ script (or serialize them). During Tier 2 evaluation, the script applies these frozen scalar constants directly to $\mathcal{D}_{\text{test\_before}}$, guaranteeing rigorous out-of-sample functional testing without test-set distribution leakage.

The raw continuous dataset is split into an observed training split $\mathcal{D}_{\text{train}} = (\mathcal{D}_{\text{train\_before}}, \mathcal{D}_{\text{train\_after}})$ of size $N_{\text{train}}$ (70\%) and a hidden holdout test split $\mathcal{D}_{\text{test}} = (\mathcal{D}_{\text{test\_before}}, \mathcal{D}_{\text{test\_after}})$ of size $N_{\text{test}}$ (30\%) using uniform pseudo-random permutation ($\text{seed}=42$), ensuring $\mathcal{D}_{\text{train}} \cap \mathcal{D}_{\text{test}} = \emptyset$ without imposing artificial stratification over continuous multi-target spaces.

\noindent\textbf{The Objective:} Given access solely to $\mathcal{D}_{\text{train\_before}}$ and $\mathcal{D}_{\text{train\_after}}$, the agent must formulate and submit an executable Python program $\widehat{\mathcal{T}}$ that maximizes the out-of-sample functional column recovery on hidden test data:
\begin{equation}
    \max_{\widehat{\mathcal{T}}} \; \frac{1}{|\mathcal{C}_{\text{after}}|} \sum_{c \in \mathcal{C}_{\text{after}}} \mathbf{1}_{\{m(c) \ge 0.99\}}
\end{equation}
where $m(c)$ is the column match accuracy under relative/absolute tolerance $\epsilon = 10^{-4}$ (defined in Eq.~\ref{eq:col_match}), while simultaneously recovering the ground-truth symbolic operator multiset $\mathcal{O}^* \subseteq \Omega$.

\subsection{Six Structural Complexity Classes}
To systematically benchmark reasoning capacity across expression tree topologies, we formalize six structural complexity classes governed by exact column counts $|\mathcal{C}_{\text{trans}}|$ and DAG depth $d$:
\begin{itemize}
    \item \textbf{Class 0 (Atomic Unary):} Exactly $|\mathcal{C}_{\text{trans}}| = 1$ column transformed by a single primitive operation $y = f(x)$ at depth $d=1$, with 0 interactions.
    \item \textbf{Class 1 (Independent Unary):} Exactly $|\mathcal{C}_{\text{trans}}| = 2$ distinct independent columns transformed concurrently by uncomposed unary functions: $y_j = f_j(x_j)$ ($d=1$, 0 interactions).
    \item \textbf{Class 2 (Composed Chains):} Exactly $|\mathcal{C}_{\text{trans}}| = 3$ independent columns undergoing sequential two-step compositions ($d=2$, 0 interactions): $y_j = f_{j,2}(f_{j,1}(x_j))$, requiring intermediate state tracking.
    \item \textbf{Class 3 (Multi-Column Interactions):} Exactly $|\mathcal{C}_{\text{trans}}| = 4$ columns: 3 independent composed unary transformations at depth $d=2$ plus 1 bivariate cross-column interaction $z = x_i \star x_j$ with $\star \in \{+, -, \times, \div\}$.
    \item \textbf{Class 4 (Piecewise / Conditional Logic):} Exactly $|\mathcal{C}_{\text{trans}}| = 4$ columns: 3 independent composed unary transformations at depth $d=2$ prioritized with conditional/piecewise unary operators from $\Omega_5$, plus 1 conditional cross-column interaction $z = \mathbf{1}_{\{x_j > \theta\}} \cdot x_i$, requiring continuous threshold estimation $\theta$ (derived from training empirical quantiles):
    \begin{equation}
        y = \begin{cases} f(x) & \text{if } x > \theta, \\ 0 & \text{otherwise} \end{cases} \quad \text{or} \quad z = \begin{cases} x_i & \text{if } x_j > \theta, \\ 0 & \text{otherwise} \end{cases}
    \end{equation}
    where $\text{PiecewiseLog}$ is implemented via guarded vectorization ($\texttt{np.where}(x > 0, \ln(\max(x, 10^{-12})), 0.0)$) to prevent non-finite runtime exceptions over zero or negative domain values.
    \item \textbf{Class 5 (Deep Hybrid AST):} Up to $|\mathcal{C}_{\text{trans}}| \le 6$ columns forming a Directed Acyclic Graph (DAG) that integrates multi-step sequential compositions up to depth $d=3$, multiple cross-column interactions, and unary operations applied directly on top of interaction outputs ($y = f(x_i \star x_j)$).
\end{itemize}
In-place column transformations and cross-column interactions in $\mathcal{T}$ read in parallel from an immutable snapshot of $\mathcal{D}_{\text{before}}$, preventing sequential pipeline mutations from altering source dependencies.

\subsection{Two-Tier Epistemic Isolation Harness}
Our harness implements strict two-tier isolation to guarantee experimental validity and host security (Figure~\ref{fig:two_tier_arch}):

\subsubsection{Tier 1: Agentic Discovery Sandbox}
The agent operates in an isolated Python workspace via three LangChain tools:
\begin{itemize}
    \item $\texttt{run\_python}(\texttt{code})$: Acts as an interactive REPL. To ensure complete execution safety and prevent dirty state corruption, each call runs in a freshly spawned Python subprocess with stripped host environment variables ($\texttt{API\_KEY}$, $\texttt{TOKEN}$) and an enforced 15-second timeout. Process RAM is stateless between tool calls; persistent variables, figures, and artifacts are maintained exclusively across conversational turns and disk files. The observed training tables $\mathcal{D}_{\text{train\_before}}$ and $\mathcal{D}_{\text{train\_after}}$ are mounted as read-only CSV files, preventing exploratory scripts from mutating baseline data.
    \item $\texttt{read\_image}(\texttt{path})$: Loads visual diagnostic charts (residual distribution curves, scatter plots) generated by the agent into the multimodal LLM context, assisting piecewise threshold detection.
    \item $\texttt{submit\_solution}(\texttt{script}, \widehat{\mathcal{O}})$: Formally terminates the discovery episode by submitting a self-contained Python script defining $\texttt{transform}(\texttt{df})$ alongside the agent's identified symbolic operator list $\widehat{\mathcal{O}}$.
\end{itemize}

\subsubsection{Adaptive Tiered Budget Controller}
Discovery episodes are strictly bounded by an adaptive budget parameterized by complexity class $c \in \{0, \dots, 5\}$:
\begin{align}
    T_{\text{calls}}(c) &\in (8, 10, 14, 18, 24, 30), \\
    K_{\text{tokens}}(c) &\in (60\text{k}, 80\text{k}, 120\text{k}, 160\text{k}, 220\text{k}, 300\text{k}), \\
    \Delta t_{\text{wall}}(c) &\in (120\text{s}, 120\text{s}, 180\text{s}, 240\text{s}, 300\text{s}, 360\text{s}),
\end{align}
where $T_{\text{calls}}$ is maximum tool invocations, $K_{\text{tokens}}$ denotes total cumulative input and output tokens consumed across the episode, and $\Delta t_{\text{wall}}$ is the wall-clock timeout. If any threshold is breached, the episode gracefully terminates.

\subsubsection{Tier 2: Independent Evaluation Sandbox}
Upon solution submission, the harness launches an independent evaluation container allocated with 2GB RAM and an execution timeout of 30 seconds. Epistemic isolation is enforced through container filesystem segregation and network disabling: $\mathcal{D}_{\text{test\_before}}$ is mounted read-only, while ground-truth targets $\mathcal{D}_{\text{test\_after}}$ reside securely in host memory and are never mounted to any container. As a defense-in-depth measure, submitted scripts are statically parsed via Abstract Syntax Tree (AST) analysis to reject forbidden syscalls ($\texttt{subprocess}$, socket connections, arbitrary filesystem writes) prior to execution.


\subsection{Evaluation Metrics}
We assess performance across two orthogonal dimensions: functional numerical execution and symbolic structural recovery. Importantly, we formalize both \emph{conditional} and \emph{penalized} metrics to address non-submission failure modes.

\subsubsection{Black-Box Functional Metrics}
Let $\mathcal{C}_{\text{after}}$ denote the target column schema. For column $c \in \mathcal{C}_{\text{after}}$, the column match accuracy over $N_{\text{test}}$ rows is:
\begin{equation}
\label{eq:col_match}
    m(c) = \frac{1}{N_{\text{test}}} \sum_{i=1}^{N_{\text{test}}} \mathbf{1}_{\left\{ |\widehat{D}_{i, c} - D_{i, c}| < \epsilon \cdot (|D_{i, c}| + 1) \right\}}
\end{equation}
with numerical tolerance $\epsilon = 10^{-4}$. Missing, non-finite ($\texttt{NaN}$, $\texttt{Inf}$), or unaligned columns receive $m(c) = 0$. A column is marked correct if $m(c) \ge 0.99$. We compute:
\begin{itemize}
    \item \textbf{Transformed Column Accuracy ($\text{Acc}_{\text{trans}}$):} The fraction of truly transformed columns $\mathcal{C}_{\text{trans}} \subseteq \mathcal{C}_{\text{after}}$ correctly predicted:
    \begin{equation}
        \text{Acc}_{\text{trans}} = \frac{1}{|\mathcal{C}_{\text{trans}}|} \sum_{c \in \mathcal{C}_{\text{trans}}} \mathbf{1}_{\{m(c) \ge 0.99\}}
    \end{equation}
    \item \textbf{Functional Column Accuracy ($\text{Acc}_{\text{func}}$):} The overall fraction of all columns in $\mathcal{C}_{\text{after}}$ (including unmodified columns) correctly predicted across the table.
\end{itemize}

\subsubsection{Conditional vs. Penalized Accuracy}
An agent may exhaust its allocated tool budget or execution timeout without executing $\texttt{submit\_solution}$. To ensure transparent, uninflated evaluation:
\begin{itemize}
    \item \textbf{Conditional Accuracy} ($\text{Acc}_{\text{cond}}$): Metrics calculated strictly across the subset of tasks where the agent explicitly submitted a solution. This quantifies the model's reasoning precision when it commits to a hypothesis.
    \item \textbf{Penalized Accuracy} ($\text{Acc}_{\text{pen}}$): Any task where the agent fails to submit within budget receives a score of \textbf{0}. Formally:
    \begin{equation}
    \begin{split}
        \text{Acc}_{\text{pen}} &= \frac{1}{N_{\text{total}}} \sum_{i=1}^{N_{\text{total}}} \mathbf{1}_{\{\text{submitted}_i\}} \cdot \text{Acc}_i \\
        &= \text{Submission Rate} \times \text{Acc}_{\text{cond}}
    \end{split}
    \end{equation}
\end{itemize}
Evaluating both perspectives prevents models with low submission rates from appearing artificially superior due to selective submission.

\subsubsection{White-Box Symbolic Metrics and Algebraic Equivalence}
The harness parses the submitted script into an AST via Python's $\texttt{ast}$ module to extract the authoritative executed operator sequence $\widehat{\mathcal{O}}_{\text{AST}}$, verifying consistency against the agent's self-reported $\widehat{\mathcal{O}}$ in $\texttt{submit\_solution}$ (with $\widehat{\mathcal{O}}_{\text{AST}}$ serving as the definitive ground of evaluation). Compared against ground-truth $\mathcal{O}^*$, we compute:
\begin{itemize}
    \item \textbf{Operator F1 Score ($\text{F1}_{\text{op}}$):} Harmonic mean of precision and recall over multiset elements, with explicit zero-division guards:
    \begin{equation}
        \text{Precision} = \begin{cases} \frac{|\widehat{\mathcal{O}} \cap \mathcal{O}^*|}{|\widehat{\mathcal{O}}|} & \text{if } |\widehat{\mathcal{O}}| > 0, \\ 0 & \text{if } |\widehat{\mathcal{O}}| = 0, \end{cases} \quad \text{Recall} = \frac{|\widehat{\mathcal{O}} \cap \mathcal{O}^*|}{|\mathcal{O}^*|}
    \end{equation}
    \item \textbf{Exact Sequence Accuracy ($\text{Acc}_{\text{seq}}$):} Measured at the column level as the fraction of transformed columns where the full composition operator sequence matches ground truth in identical topological order:
    \begin{equation}
        \text{Acc}_{\text{seq}} = \frac{1}{|\mathcal{C}_{\text{trans}}|} \sum_{c \in \mathcal{C}_{\text{trans}}} \mathbf{1}_{\{\widehat{\mathcal{O}}_c = \mathcal{O}^*_c\}}
    \end{equation}
    where DAG branches are canonicalized via depth-first topological linearization, and non-commutative binary interactions enforce exact left-to-right operand indexing.
\end{itemize}
\noindent\textbf{Syntactic Matching vs. Algebraic Equivalence:} Exact symbolic matching operates at the AST token level after canonical normalization (e.g., resolving equivalent pandas and numpy function calls such as $\texttt{np.log1p(df[c])}$ versus $\texttt{df[c].apply(np.log1p)}$, or primitive arithmetic expressions like \texttt{df[c] * df[c]} to $\text{Square}$). However, purely syntactic AST comparisons cannot recognize higher-order algebraic equivalences (such as $x_i + x_j \equiv x_j + x_i$, or affine reparameterizations of scalers). This theoretical limitation underlines why our two-tier evaluation pairs White-Box Symbolic Metrics with Black-Box Functional Correctness: functional evaluation definitively verifies out-of-sample numerical equivalence regardless of syntactic variation, while symbolic metrics assess structural hypothesis recovery.

\section{Experimental Setup}

\subsection{Benchmark Task Construction}
To satisfy stringent real-world validity requirements, we compiled 48 standardized benchmark tasks ($N=48$) sourced from eight diverse domains in the UCI Machine Learning Repository~\cite{dua2019uci} and OpenML~\cite{vanschoren2014openml}, covering diverse sample sizes and feature dimensionalities:
\begin{enumerate}
    \item \textbf{Fluid Acoustics:} \textsf{airfoil\_self\_noise} ($N=1,503$, $N_{\text{train}}=1,052$, $N_{\text{test}}=451$; 6 attributes: 5 physical aerodynamics features plus sound pressure level).
    \item \textbf{Clinical Medicine:} \textsf{diabetes} ($N=768$, $N_{\text{train}}=537$, $N_{\text{test}}=231$; 8 diagnostic indicators).
    \item \textbf{Materials Science:} \textsf{concrete\_strength} ($N=1,030$, $N_{\text{train}}=721$, $N_{\text{test}}=309$; 8 chemical mixture ratios).
    \item \textbf{Telemetry:} \textsf{cpu\_small} ($N=8,192$, $N_{\text{train}}=5,734$, $N_{\text{test}}=2,458$; 12 system metrics).
    \item \textbf{Food Chemistry:} \textsf{wine\_quality} ($N=1,599$, $N_{\text{train}}=1,119$, $N_{\text{test}}=480$; 11 physicochemical properties).
    \item \textbf{Oncology / Pathology:} \textsf{breast\_cancer} ($N=569$, $N_{\text{train}}=398$, $N_{\text{test}}=171$; 30 nuclear morphology features).
    \item \textbf{Economics / Real Estate:} \textsf{california\_housing} ($N=20,640$, $N_{\text{train}}=14,448$, $N_{\text{test}}=6,192$; 8 census block attributes).
    \item \textbf{Signal Processing / Security:} \textsf{banknote\_authentication} ($N=1,372$, $N_{\text{train}}=960$, $N_{\text{test}}=412$; 4 wavelet transform statistical moments).
\end{enumerate}

\noindent\textbf{Precondition Rejection Sampling and Schema Integrity:} Tasks were constructed using a balanced full-factorial design: each of the eight source datasets was evaluated across all six structural complexity classes (Classes 0 through 5, yielding $8 \times 6 = 48$ tasks). All tasks were generated using reproducible random seeds ($\text{seed}=42$). To guarantee mathematical validity without fabricating or clipping empirical distributions, the task generator applies \emph{rejection sampling on the raw data}: an operator is only eligible for a column if the column's raw values strictly satisfy its domain constraints (e.g., $x > 0$ for $\text{Log}$, $x \ge 0$ for $\text{Sqrt}$, non-zero divisors for $\text{Divide}$, non-zero variance $\sigma > 10^{-6}$ for $\text{StandardScaler}$). For zero-centered symmetric distributions with negative continuous values (such as \textsf{banknote\_authentication}), candidate pools are automatically restricted to domain-valid primitives ($\text{Square}$, $\text{Cube}$, $\text{CubeRoot}$, $\text{Sin}$, $\text{Tanh}$, $\text{StandardScaler}$, and linear interactions). Data points are never artificially distorted to fit an operator. Furthermore, in-place transformed columns retain their exact schema identifiers in $\mathcal{C}_{\text{after}}$, while interaction features in Classes 3--5 replace designated schema targets or adopt neutral indices, reading concurrently from an immutable initial snapshot of $\mathcal{D}_{\text{before}}$ to ensure column names leak no operator clues.

\subsection{Evaluated Models and Baselines}
We benchmark four representative paradigms under identical system prompts and tool schemas:
\begin{itemize}
    \item \textbf{Claude 3.5 Sonnet} (Anthropic): Evaluated using model snapshot \path{claude-3-5-sonnet-20241022}~\cite{anthropic2024claude35} as a frontier coding agent with iterative tool reasoning, orchestrated via LangGraph~\cite{langgraph2024}.
    \item \textbf{Gemini 2.0 Flash} (Google): Evaluated using snapshot \path{gemini-2.0-flash-exp} (with thinking trace)~\cite{geminiteam2025gemini} as a frontier multimodal agent with visual REPL inspection.
    \item \textbf{GPT-4o mini} (OpenAI): Evaluated using snapshot \path{gpt-4o-mini-2024-07-18}~\cite{openai2024gpt4o} as a lightweight frontier model operating under identical JSON schemas.
    \item \textbf{Symbolic Baseline} (Combinatorial Brute Force Reference): A non-LLM combinatorial reference baseline that iteratively tests candidate unary and binary operator combinations up to depth $d=3$, using residual $L_1$ norm minimization with early pruning.
\end{itemize}
All LLMs are queried using deterministic greedy decoding (temperature $T = 0.0$, top-$p = 1.0$) with fixed seed 42 to ensure strict empirical reproducibility. All models have access to $\texttt{run\_python}$ and $\texttt{submit\_solution}$; multimodal models (Claude and Gemini) additionally have access to $\texttt{read\_image}$.

\subsubsection{API Infrastructure and Reverse Proxy Relay}
To ensure robust, equitable, and reproducible execution across heterogeneous model providers (Anthropic, Google, and OpenAI), all LLM inference calls were orchestrated through a centralized Kaggle-hosted reverse proxy and endpoint relay. Rather than establishing unconstrained client connections from worker nodes directly to public provider APIs, the proxy architecture provides four critical operational guarantees:
\begin{enumerate}
    \item \textbf{Host Credential Scrubbing:} API authentication keys are stored exclusively within the secure proxy environment and are strictly scrubbed from agent sandboxes and worker environments, preventing malicious or accidental credential extraction during arbitrary code execution.
    \item \textbf{Centralized Concurrency and Rate-Limit Management:} The proxy enforces dynamic token bucket pacing and exponential-backoff retry policies across parallel task workers, preventing API burst rejections (HTTP 429) and ensuring uninterrupted evaluation trajectories.
    \item \textbf{Independent Telemetry and Token Auditing:} Input and output token counters (including internal thinking trace tokens for Gemini 2.0 Flash) are metered independently at the proxy ingress/egress boundaries, guaranteeing uniform token accounting across differing provider accounting standards.
    \item \textbf{Network Latency Homogenization:} All agent workers communicate with a co-located regional proxy relay, decoupling execution wall-clock limits ($\Delta t_{\text{wall}}$) from transient external transcontinental network fluctuations.
\end{enumerate}

\subsection{Ablation Study Configurations}
To disentangle hypothesis discovery from programmatic synthesis, we evaluate agent performance on Gemini 2.0 Flash across the full balanced benchmark suite of $N=48$ tasks (spanning all 8 domains $\times$ 6 complexity classes):
\begin{enumerate}
    \item \textbf{Direct Symbolic Generation (No Tools):} The agent receives data schemas and statistical summaries but cannot execute code ($\texttt{run\_python}$ disabled). It must directly synthesize the $\texttt{transform}$ script in a single shot. In this mode, 33 out of 48 tasks were unsubmitted (31.2\% submission rate) due to syntax errors, invalid tool calls, or runtime exceptions that could not be debugged without REPL feedback.
    \item \textbf{Standard Interactive Discovery (Full Agent):} The standard two-tier harness where the agent iteratively tests hypotheses in the REPL sandbox before submission.
    \item \textbf{Oracle Operators Revealed (Synthesis Only):} Ground-truth operator names $\mathcal{O}^*$ are provided in the prompt. The agent still uses the $\texttt{run\_python}$ REPL to resolve the remaining challenges: determining which operator maps to which column, ordering the DAG, and optimizing continuous parameters (e.g., threshold $\theta$ or scaler coefficients). With operator hints provided, submission rate rises to 77.1\% (37 out of 48 tasks), while 11 tasks remained unsubmitted due to budget exhaustion when optimizing complex continuous thresholds or multi-column interactions.
\end{enumerate}

\subsection{Cross-Model Comparison Across Complexity Classes}

\subsubsection{Frontier Agents vs. Lightweight Frontier Model}
Evaluating both conditional accuracy ($\text{Acc}_{\text{cond}}$, evaluated on submitted tasks) and penalized accuracy ($\text{Acc}_{\text{pen}}$, penalizing unsubmitted tasks with 0.0) reveals crucial differences in agentic behavior and reasoning competence:
\begin{itemize}
    \item \textbf{Claude 3.5 Sonnet} achieves the highest overall task submission rate among LLM agents (\textbf{70.8\%}, 34/48 tasks) and the highest Penalized Transformed Column Accuracy among LLMs (\textbf{0.575}), surpassing both Gemini 2.0 Flash (0.422) and GPT-4o mini (0.524). Its functional penalized accuracy reaches \textbf{0.667}. On atomic unary tasks (Class 0) and independent transformations (Class 1), Claude achieves a 100\% submission rate (8/8 tasks) with a penalized accuracy of \textbf{0.875}. On deep hybrid ASTs (Class 5), it maintains a 50\% submission rate (4/8 tasks) and 0.625 conditional transformed accuracy (\textbf{0.313} penalized, where $0.500 \times 0.625 = 0.313$).
    \item \textbf{Gemini 2.0 Flash} achieves an outstanding conditional Transformed Accuracy of \textbf{0.844} and Functional Accuracy of \textbf{0.936} when it commits to a solution, alongside an Operator F1 of \textbf{0.853}. However, it exhibits an over-conservative stopping policy: when residual error does not reach numerical tolerance ($\|\widehat{\mathcal{D}} - \mathcal{D}\|_\infty < 10^{-6}$), it continues iterating within the REPL sandbox until its tool budget is exhausted, rather than risking a partial submission. Consequently, Gemini 2.0 Flash achieves a submission rate of \textbf{50.0\%} (24/48 tasks), resulting in an overall penalized transformed accuracy of $0.500 \times 0.844 = \mathbf{0.422}$.
    \item \textbf{GPT-4o mini} achieves a 100.0\% submission rate, but displays substantial performance degradation as complexity increases: from 1.000 at Class 0 down to 0.875 (Class 1), 0.333 (Class 2), 0.312 (Class 3), with a partial rebound to 0.375 (Class 4), and reaching 0.250 at Class 5, with an overall Operator F1 of only 0.400. While GPT-4o mini never exhausts its budget without submitting, its synthesized scripts frequently hallucinate column names and fail to invert non-linear compositions.
\end{itemize}

\subsubsection{Trade-offs in Combinatorial Enumeration vs. Agentic Search}
The non-LLM Symbolic Enumeration baseline achieves an overall penalized transformed accuracy of \textbf{0.653} (functional accuracy 0.781) across all 48 tasks. This nominal advantage over Claude's penalized score (0.575) stems directly from its policy of unconditional 100\% submission (48/48 tasks) without fear of budget abandonment. However, a deeper examination reveals critical architectural trade-offs:

First, when considering conditional precision upon submission, frontier LLMs substantially outperform the baseline: Gemini 2.0 Flash achieves \textbf{0.844} conditional transformed accuracy and Claude 3.5 Sonnet achieves \textbf{0.811}, compared to the baseline's unselective \textbf{0.653}.

Second, on atomic and low-depth classes where an exhaustive depth-1 search space is strictly bounded (19 unary operators $\times M$ columns), the baseline surprisingly achieves only \textbf{0.750} on Class 0 and Class 1, and \textbf{0.562} on Class 3 (compared to \textbf{0.667} on Class 2 and \textbf{0.812} on Class 4). This sub-optimal performance on elementary transformations arises because: (i) greedy $L_1$ residual minimization can be trapped by collinear surrogate features in dense datasets (such as \textsf{california\_housing} or \textsf{airfoil\_self\_noise}), selecting algebraically pseudo-correlated operations; and (ii) the baseline lacks stateful parameter persistence for scalers ($\mu, \sigma$ and $\min, \max$), causing generalization loss on test holdouts. Conversely, on Class 4 (0.812), the baseline's threshold search employs quantile-based candidate splits (median, quartiles), which closely mirrors the empirical data partitioning.

Finally, on Class 5 (Deep Hybrid ASTs), combinatorial search suffers exponential explosion ($\mathcal{O}(M^d \cdot |\Omega|^d)$). The baseline collapses to \textbf{0.375}. While this 0.375 penalized score technically exceeds Claude's 0.313 penalized score (which was halved by conservative non-submissions), Claude's conditional accuracy when committing to a solution reaches \textbf{0.625}, proving that agentic hypothesis testing can resolve complex multi-operator DAGs that defeat exhaustive search.

\subsection{Ablation Study: Disentangling Discovery from Synthesis}
Table~\ref{tab:ablation_study} presents the results of our three-mode ablation study on Gemini 2.0 Flash across the full benchmark suite ($N=48$). In the \textbf{Standard Interactive Discovery (Full Agent)} condition, Gemini 2.0 Flash submits solutions for 24 out of 48 tasks (50.0\% submission rate), attaining a conditional transformed accuracy of \textbf{0.844} (penalized transformed accuracy of $24/48 \times 0.844 = \mathbf{0.422}$), a conditional functional accuracy of \textbf{0.936}, an Operator F1 of \textbf{0.853}, and a column exact sequence accuracy of \textbf{0.736}.

\subsubsection{The Necessity of Interactive REPL Feedback}
Under the \textbf{Direct Symbolic Generation (No Tools)} condition, performance collapses catastrophically: Transformed Column Accuracy drops to \textbf{0.050} (5.0\% conditional, 1.6\% penalized), and Operator F1 drops to \textbf{0.000}. Although the model generates syntactically valid Python scripts, its parametric weights cannot mentally execute non-linear continuous mathematical transformations over tabular arrays. This proves conclusively that interactive tool use and empirical REPL feedback are non-negotiable prerequisites for inverse tabular reasoning.

\subsubsection{Is Code Synthesis or Hypothesis Search the Bottleneck?}
Under the \textbf{Oracle Operators Revealed} condition—where the ground-truth operator vocabulary is disclosed—the agent submits solutions on 37 out of 48 tasks (77.1\% submission rate) and achieves \textbf{0.989} (98.9\%) Transformed Accuracy, \textbf{0.976} Functional Accuracy, and perfect \textbf{1.000} (100.0\%) Operator F1 and Column Exact Sequence Accuracy conditioned on submitted tasks (penalized transformed accuracy of $37/48 \times 0.989 = \mathbf{0.762}$). This result provides a key insight:
\begin{quote}
\emph{When the latent mathematical operations are disclosed, programmatic code compilation achieves near-perfect fidelity in frontier LLMs on submitted tasks. The primary bottleneck in autonomous tabular discovery is hypothesis generation, operator disambiguation, and budget-aware stopping under observational uncertainty.}
\end{quote}

\section{Discussion and Limitations}

\subsection{Threats to Validity and Data Leakage}
A prominent threat in LLM evaluation is pre-training data contamination. In our harness, this threat is mitigated by design: while raw baseline datasets originate from public repositories, the transformation pipelines $\mathcal{T}$ and resulting target tables $\mathcal{D}_{\text{after}}$ are synthetically generated on-the-fly with unique parameterized AST graphs. Furthermore, Tier 2 evaluation strictly isolates $\mathcal{D}_{\text{test\_after}}$ in host memory, preventing memory inspection attacks.

Nevertheless, an inherent subtlety arises from using authentic empirical datasets: while the transformations are novel, the input feature distributions and column semantics in $\mathcal{D}_{\text{before}}$ originate from well-known public benchmarks (e.g., UCI and OpenML). Models may thus possess pre-training familiarity with domain feature correlations (e.g., recognizing the clinical relationship between glucose and insulin in \textsf{diabetes}, or geographic coordinates in \textsf{california\_housing}), which provides an inductive prior that aids feature disambiguation. In extreme cases, models might even exhibit memorization of exact numerical rows or marginal moments from heavily cited benchmark splits. While real-world data science frequently leverages such semantic schema priors, developing completely synthetic, semantically blinded tabular manifolds and applying affine perturbations represent important directions to benchmark pure numeric induction devoid of textual priors.

\subsection{Limitations}
While our framework establishes a rigorous foundation for evaluating inverse tabular induction, several limitations warrant discussion:
\begin{enumerate}
    \item \textbf{Discrete Operator Vocabulary:} Our evaluation currently benchmarks a predefined library of 24 canonical statistical and mathematical transformations. While this library covers a wide spectrum of common feature engineering techniques, real-world data pipelines may incorporate domain-specific proprietary transformations or continuous parameter estimations that require continuous gradient optimization.
    \item \textbf{Noise-Free Deterministic Mapping Assumption:} Our problem formulation assumes that $\mathcal{D}_{\text{after}}$ is generated by a deterministic mathematical mapping $\mathcal{T}$ free from exogenous stochastic noise or unobserved measurement error. In real-world enterprise ETL and data engineering contexts, tabular records are frequently corrupted by sensor noise, missing values, and asynchronous timestamp misalignment. Extending the inverse reasoning formulation to identify underlying functional trends in the presence of heteroscedastic noise represents a vital next step.
    \item \textbf{Agent Stopping Heuristics and Budget Sensitivity:} As demonstrated by the divergence between Claude 3.5 Sonnet (70.8\% submission rate) and Gemini 2.0 Flash (50.0\% submission rate), frontier agents vary significantly in their stopping heuristics under hard budget constraints. For Gemini 2.0 Flash, internal thinking traces and iterative REPL numerical verifications consumed significant portions of the token and tool budget, leading to conservative timeouts. Designing risk-aware decision policies that balance exploration against submission urgency is an essential direction for autonomous scientific agents.
    \item \textbf{Multimodal Vision Tool Overhead and Confounding:} While visual chart inspection via $\texttt{read\_image}$ enables models to visually identify threshold boundaries and non-linear trends, empirical inspection of agent execution traces reveals that models invoked $\texttt{read\_image}$ selectively (primarily during Class 4 and 5 tasks for threshold inspection). Generating and ingesting image artifacts incurs non-trivial token consumption and execution latency against strict episode budgets. While GPT-4o mini operated with text-only REPL tools under our setup, conducting an isolated ablation systematically disabling vision tools across multimodal architectures to quantify the precise trade-off between visual intuition and token overhead remains an important future endeavor.
    \item \textbf{Scope of Symbolic Baselines:} Our non-LLM baseline evaluates exhaustive combinatorial brute-force enumeration up to depth 3 as a naive reference. While this demonstrates the combinatorial explosion of unguided search, established heuristic and evolutionary symbolic regression frameworks (e.g., PySR~\cite{cranmer2023pysr}, AI Feynman~\cite{udrescu2020ai}) use genetic operators and modular decomposition to explore deeper expression trees without brute-force enumeration, although they do not natively support multi-column schemas, frozen empirical distribution scalers ($\Omega_3$), or branching piecewise conditionals ($\Omega_5$).
    \item \textbf{Single-Seed Evaluation:} Tasks were evaluated with a fixed deterministic seed ($\text{seed}=42$) to guarantee strict comparative reproducibility across models and sandboxes. While fixed-seed protocols are standard in compute-intensive agentic benchmarks, multi-seed replications would provide confidence intervals capturing stochasticity in LLM sampling and sandbox execution timing.
\end{enumerate}

\section{Conclusion}
In this work, we introduced the \textbf{Tabular Transformation Discovery Harness}, an autonomous two-tier evaluation framework for benchmarking inverse tabular reasoning in Large Language Models. By formalizing six structural complexity classes across eight authentic real-world domains and enforcing strict epistemic sandbox isolation, we provide the first rigorous benchmark disentangling hypothesis discovery from code synthesis across 48 standardized tasks ($N=48$). Our empirical results demonstrate that frontier coding agents like Claude 3.5 Sonnet achieve strong overall penalized accuracy (0.575) by balancing REPL exploration with reliable submission, while models like Gemini 2.0 Flash achieve high reasoning precision (0.844 conditional accuracy) but are bounded by conservative stopping heuristics. Our three-mode ablation study on Gemini 2.0 Flash ($N=48$) establishes that interactive REPL feedback is indispensable (improving conditional accuracy from 0.050 to 0.844), and revealing ground-truth operators unlocks near-perfect (0.989) conditional synthesis fidelity on submitted tasks. We make our benchmark suite and evaluation harnesses publicly available to accelerate research into neuro-symbolic reasoning and autonomous scientific discovery.
